# MusicMatch 🎵 — 3D Audio Data Mining & Music Recommendation

Please find the complete project under [`musicmatch/`](./musicmatch/):
- **Frontend:** [`musicmatch/frontend/`](./musicmatch/frontend/) (HTML, CSS, JS, Three.js)
- **Backend:** [`musicmatch/backend/`](./musicmatch/backend/) (Flask, Librosa, Scikit-learn)
- **Full Documentation:** [`musicmatch/README.md`](./musicmatch/README.md)

### Quick Run Commands:

**1. Start the Backend (Port 5000):**
```bash
cd musicmatch/backend
python app.py
```

**2. Open the Frontend (Port 8000 or open index.html):**
```bash
cd musicmatch/frontend
python -m http.server 8000
```
Open **http://localhost:8000** in your browser.
